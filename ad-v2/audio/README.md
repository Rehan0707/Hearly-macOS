# Hearly version 2 audio

Female Ava multilingual neural US English narration. The raw speech was generated at -12% rate, then trimmed and gently timed with pitch-preserving FFmpeg atempo. Eleven independent cues, with breath and pause space, align to the film. The brand is pronounced “Hear lee.”

Original ambient harmony, felt-synth motif, restrained bass pulse, designed typing texture, transition sweeps, selection pings, and closing three-note logo. No sampled commercial recording.

All WAV stems are stereo 48 kHz, 24-bit PCM, exactly 60 seconds. `cues.json` contains the precise voice start and end times. `create_audio.py` reproduces the sound using edge-tts, numpy, scipy and imageio-ffmpeg.
